# راهنمای راه‌اندازی ربات کاتالوگ عطر

## ⚠️ نکته مهم درباره داده‌ها
از کپی خودکار (اسکرپ) محتوای سایت‌هایی مثل Fragrantica خودداری کنید — این کار معمولاً
با قوانین استفاده و کپی‌رایت اون سایت‌ها مغایرت داره. به‌جاش، اطلاعات عطرها
(اسم، برند، نوت‌ها، توضیح کوتاه) رو با نگارش خودتون در فایل `catalog.csv` وارد کنید؛
می‌تونید از فراگرانتیکا به‌عنوان مرجع برای اطلاعات نوت‌های عطر (فکت‌های عمومی، نه متن کپی‌شده) استفاده کنید.

## مرحله ۱: ساخت ربات در تلگرام
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدید.
2. دستور `/newbot` رو بزنید و اسم و یوزرنیم دلخواه رو انتخاب کنید.
3. یک توکن به این شکل دریافت می‌کنید: `123456789:ABCdefGhIJKlmNoPQRstuVwxyZ`

## مرحله ۲: آماده کردن فایل کاتالوگ
فایل `catalog.csv` رو با اکسل باز کنید (یا `catalog.xlsx` بسازید) و ستون‌های زیر رو پر کنید:

| ستون | اجباری | توضیح |
|---|---|---|
| name | ✅ | اسم عطر |
| brand | ✅ | برند |
| notes | ✅ | نوت‌های عطر، با `;` از هم جدا بشن |
| description | ✅ | توضیح کوتاه (خودتون بنویسید) |
| price | ❌ | قیمت (اختیاری) |
| image_url | ❌ | لینک عکس (اختیاری) |

می‌تونید هم از فایل CSV و هم Excel (`.xlsx`) استفاده کنید؛ ربات هر دو رو می‌خونه.

## مرحله ۳: اجرای محلی (برای تست)
```bash
pip install -r requirements.txt
export BOT_TOKEN="توکن_شما"
python bot.py
```

## مرحله ۴: میزبانی (Hosting) — چون گفتید مطمئن نیستید کجا اجرا کنید

چون تجربه‌ی سرور ندارید، ساده‌ترین و ارزون‌ترین گزینه‌ها اینا هستن:

### گزینه ۱ (پیشنهاد اصلی): Railway.app یا Render.com
- رایگان یا خیلی ارزون برای شروع
- کافیه پروژه رو در گیت‌هاب آپلود کنید و به Railway/Render وصلش کنید
- متغیر محیطی `BOT_TOKEN` رو در پنل سایت تنظیم می‌کنید
- نیازی به دانستن لینوکس یا سرور ندارید

### گزینه ۲: یک VPS ارزون (مثل هزینه‌های ایرانی یا خارجی)
- کنترل بیشتر ولی نیاز به کمی آشنایی با لینوکس
- روی سرور: `pip install -r requirements.txt` سپس اجرا با `systemd` یا `screen`/`tmux` برای اجرای دائمی

### گزینه ۳: PythonAnywhere
- برای ربات‌های کوچک هم مناسبه، پنل ساده‌ای داره

اگه بخواید، می‌تونم مرحله به مرحله راه‌اندازی روی Railway رو هم براتون توضیح بدم — چون برای شروع ساده‌تر از همه‌ست.

## نکات بعدی برای توسعه‌ی بعدی (اختیاری)
- افزودن سبد خرید و ثبت سفارش
- اتصال به پرداخت آنلاین (زرین‌پال و مشابه)
- پنل مدیریت برای آپدیت کاتالوگ بدون نیاز به ادیت مستقیم فایل
